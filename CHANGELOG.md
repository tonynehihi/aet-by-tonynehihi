# Changelog

## After Effects by Tonynehihi 1.1.0

First release of After Effects by Tonynehihi (AeT), a personal build based on EffectCraft 0.16.0 by the ArtCraft team.

**NEW NAME AND ICON:** the app is now "After Effects by Tonynehihi" (bundle `AeT.app`) with the suite's Adobe-style icon.

**SELF-UPDATE IN THE APP:** AeT checks GitHub for a newer version at launch and shows the release notes in a popup; you can also check any time via Help → Check for Updates or the About dialog. On macOS it can download, build and install the update in place.

**NO UPSTREAM LINKS:** the ArtCraft Discord button, the GitHub/website header buttons, the Help-menu community and docs links and the Home screen's community/sibling-apps footer are removed. EffectCraft is credited in the README.

**FULL EFFECTCRAFT 0.16.0 MOTION-GRAPHICS EDITOR:** compositions, layers, keyframes, effects, expressions and rendering — unchanged under the hood.

— tonynehihi
